# Segurança

Não inclua senhas, tokens, chaves privadas, IPs privados ou exports de preferências em issues. Para relatos sem dados sensíveis, abra uma issue com versão, sistema e passos de reprodução. Para vulnerabilidades que envolvam credenciais, use a opção de relato privado do GitHub quando estiver habilitada ou contate o mantenedor antes de divulgar detalhes.

Os streams e o catálogo são serviços externos. Uma URL manual só aceita HTTP(S) e não aceita credenciais embutidas na edição compartilhada. O usuário controla o acesso a servidores locais e VPNs. Atualizações abrem a release oficial e dependem de instalação escolhida pelo usuário.

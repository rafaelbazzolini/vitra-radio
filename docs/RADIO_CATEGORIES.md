# Categorias de rádios

Em **Todas as rádios**, use **Treino**, **Trabalho** ou **Meditação** para filtrar uma seleção internacional e os vínculos salvos no dispositivo. A busca por nome também filtra essa seleção. **Todas** retorna à pesquisa por países no Radio Browser.

Use o botão de etiqueta no cartão da rádio para marcar ou desmarcar uma ou mais categorias. Isso guarda a emissora na biblioteca, sem favoritar ou iniciar sua reprodução. Os vínculos são locais: não são enviados ao Radio Browser nem compartilhados com outros usuários. Remover uma categoria de uma sugestão também fica salvo.

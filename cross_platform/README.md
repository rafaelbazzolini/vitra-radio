# Vitra Radio — edição compartilhada

App Flutter responsivo para Windows 11, Linux, Android, iOS e macOS. Veja o [README principal](../README.md) para recursos, instalação e limitações em relação ao app nativo.

```sh
flutter pub get
flutter analyze
flutter test
flutter run
```

A instalação começa vazia. Sem contas, rádios ou servidores do desenvolvedor. O build iOS sem assinatura não é instalável; siga o [guia de release](../docs/RELEASING.md).
